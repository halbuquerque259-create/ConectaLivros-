# RF02 — Informações das Obras Literárias

**COMO** usuário da plataforma Conectar Livros,

**QUERO** visualizar informações detalhadas sobre as obras literárias,

**PARA** conhecer melhor os livros antes de iniciar uma leitura.



## Critérios de Aceitação:

- O sistema deve exibir o título da obra
- O sistema deve exibir o autor do livro
- O sistema deve exibir a categoria literária
- O sistema deve exibir o número de páginas
- O sistema deve exibir uma descrição da obra
