# RF05 — Descoberta de Novos Livros

**COMO** usuário da plataforma Conectar Livros,

**QUERO** descobrir novos livros,

**PARA** encontrar novas obras de acordo com meus interesses.



## Critérios de Aceitação:

- O sistema deve recomendar livros ao usuário
- O sistema deve permitir busca por categorias
- O sistema deve permitir busca por autores
- O sistema deve exibir sugestões de leitura
- O sistema deve permitir visualizar livros populares
