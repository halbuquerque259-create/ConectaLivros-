# RF01 — Visualização de Livros

**COMO** usuário da plataforma Conectar Livros,

**QUERO** visualizar os livros cadastrados no sistema,

**PARA** encontrar obras de interesse e acompanhar as leituras disponíveis.



## Critérios de Aceitação:

- O sistema deve listar os livros cadastrados
- O sistema deve exibir o título da obra
- O sistema deve exibir o nome do autor
- O sistema deve exibir a categoria do livro
- O sistema deve informar se o livro está disponível
