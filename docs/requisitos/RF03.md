# RF03 — Cadastro e Login de Usuários

**COMO** visitante da plataforma Conectar Livros,

**QUERO** criar uma conta e realizar login no sistema,

**PARA** acessar funcionalidades personalizadas da plataforma.



## Critérios de Aceitação:

- O sistema deve permitir o cadastro de usuários
- O sistema deve solicitar nome, e-mail e senha
- O sistema deve validar e-mails já cadastrados
- O sistema deve permitir login com e-mail e senha
- O sistema deve impedir acesso com senha incorreta
