# RF04 — Organização de Leituras

**COMO** usuário da plataforma Conectar Livros,

**QUERO** organizar minhas leituras,

**PARA** acompanhar livros já lidos, em andamento e futuros.



## Critérios de Aceitação:

- O usuário deve poder adicionar livros à sua lista de leitura
- O usuário deve poder marcar livros como “Lido”
- O usuário deve poder marcar livros como “Lendo”
- O usuário deve poder marcar livros como “Quero Ler”
- O sistema deve salvar as informações de leitura do usuário
